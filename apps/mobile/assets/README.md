# Reference assets

The mobile UI follows the user's approved three-screen BeanMora reference.

- images/home-banner.jpg: bundled banner photograph reconstructed with the built-in image-generation tool from the supplied mockup. Prompt: recover only the home banner photograph, preserving the cappuccino, latte art, coffee beans, rustic wood, burlap, warm lighting and composition; remove the UI text and button.
- images/login-background.jpg: bundled login photograph reconstructed with the same tool. Prompt: recover only the far-right portrait background, preserving the portafilter, espresso stream, dark cafe bokeh and coffee beans; remove the logo, text, form and controls.
- images/coffee-bag.jpg, coffee-beans.jpg, coffee-cherries.jpg: photographic regions extracted from the user-supplied reference. These are **illustrative**, never attributed to a particular catalog product. The UI identifies them accordingly and prefers approved real product images.
- images/xbloom.jpg, grinder.jpg, scale.jpg: equipment artwork extracted from that reference, used for category cards.
- fonts/Tajawal-Regular.ttf, Tajawal-Bold.ttf: Google Fonts Tajawal, bundled for consistent offline Arabic typography. License: fonts/OFL.txt.

Runtime images remain subject to the catalog's image_usage_status. A roaster logo is not a product photo. Broken or missing approved photos fall back to bundled illustrative artwork.
