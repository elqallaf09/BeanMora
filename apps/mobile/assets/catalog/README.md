# Catalog photo copies

`crossbridge-oasis.png` is a lossless PNG copy of the source photograph for the specialty Oasis Blend, not generated artwork. The visible bag names Oasis Blend, and the archived official caption specifies Uganda, Brazil and Colombia. This exact photograph and association were approved by the existing catalog-media audit; see `supabase/research/catalog-media-2026-10-04/evidence/rescue-source-evidence.json`.

- Original image: https://images.squarespace-cdn.com/content/v1/5626184ce4b0581ff0294cfe/1593350415515-UAU8BG9WMUYTUTU2LK6P/image-asset.jpeg
- Official source archived: https://web.archive.org/web/20240822132556/https://crossbridgecoffee.com/
- Retrieved in the 4 October 2026 catalog audit and rechecked 5 October 2026. PNG, 640 × 640. The CDN currently returns WebP; the retained PNG uses the same approved photograph and works consistently in native iOS and Android.

The source and image-source links remain on the coffee. A bundled copy loads the approved bag photo reliably in coffee details, catalog cards and inventory without depending on the remote CDN. It is used only when the published catalog references this exact image URI; it does not replace other coffees' photos.
