# BeanMora 0.5.35 — الترجمة والبحث وفحص الأمان

تاريخ الفحص: 14 أكتوبر 2026. النسخة اجتازت الفحص المحلي. أُجيز رفعها إلى GitHub والدمج بعد نجاح فحوصه ونشر تحديث الويب؛ يُسجل تحقق النشر الفعلي في طلب الدمج. تحديثات قاعدة البيانات المذكورة في وثيقة الإصدار طُبقت على مشروع BeanMora فقط.

## اللغات والكتابة

العربية والإنجليزية واليابانية والفرنسية والإيطالية والإسبانية والبرتغالية البرازيلية والصينية المبسطة متاحة في إعدادات تطبيق Expo. ملفات الترجمة تغطي 3٬095 عبارة مسجلة. شملت المراجعة مصطلحات القهوة والإيحاءات والوحدات والدروس والنصوص القانونية ورسائل الخطأ. يحتفظ التطبيق بأسماء المنتجات والمصادر، وبنصوص الأعضاء كما كتبوها؛ لا يترجم أي محتوى حر ترجمة عامة تلقائيًا.

نجحت اختبارات واجهة باللغات الثماني للبحث بكلمات أصلية ومركبة، وحفظ اللغة، والبحث عن الدولة، وتسجيل بيانات البلد والهاتف، وإرسال وصفة خاصة مع إبقاء الاسم والخطوات الأصلية. تُقبل الأرقام العربية والكاملة العرض، والفاصلة العشرية في اللغات الأربع التي تستخدمها. تُرفض الفواصل المختلطة أو المقادير غير الصحيحة.

قاموس البحث يتضمن 446 مفهومًا، ويشمل الدول والإيحاءات. يحافظ البحث على جميع شروط الطلب وعلى الأسماء غير المعروفة. فُصلت الأسماء المتشابهة بين الدول والإيحاءات، وحُفظ الفرق بين الكلمات الفرنسية ذات العلامات المختلفة. المساعد يفهم طلب موقع بيع مكائن الإسبريسو وطلب وصفة xBloom الباردة بجوز الهند والعسل. لا يعتبر معالجة العسل دليلًا على إيحاء العسل، ولا يغيّر وحدات المصدر أو يخمّن مقادير ناقصة.

## نتائج الأمان

| الفحص | النتيجة |
| --- | --- |
| اعتمادات مشروع الويب، بما فيها أدوات التطوير | صفر نتائج في npm audit |
| اعتمادات أدوات بناء الموبايل | 15 نتيجة عالية في الفحص الخام مرتبطة بمكتبتين؛ الإصلاحان المحليان مثبتان ومختبران، ولا توجد استثناءات مخاطر |
| اختبارات الاستغلال وسلامة الإصلاحات | 36 اختبارًا للموبايل و9 اختبارات أمنية للويب ناجحة |
| ملفات تشغيل iOS وAndroid والويب | لا تتضمن braces أو node-forge بحسب خرائط المصادر |
| فحص مفاتيح سرية في ملفات الإصدار | لم يُكشف مفتاح خاص أو GitHub/AWS/Supabase service-role ضمن الأنماط المفحوصة |
| جداول API المقروءة دون RLS | صفر |
| بيانات خاصة وصلاحيات الزائر | اختبارات عزل الوصفات والمراسلات، ومنع صلاحيات صيانة البحث والإشراف والحذف للزائر، ناجحة |
| خصوصية المتابعين وزيارات الحساب والقصص | اختبارات الخصوصية والانتحال والحسابات المجهولة ناجحة، مع إلغاء جميع بيانات الاختبار |
| حقن أو توسيع استعلام البحث | المدخلات تبقى معاملات حرفية، وجميع الشروط مطلوبة، والوصفات الخاصة لا تظهر |
| امتدادات قاعدة البيانات المكشوفة | نُقل unaccent وpg_trgm إلى extensions؛ تنبيها وجودهما في public أُزيلا |

مكتبتا أدوات البناء هما [braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) و[node-forge](https://github.com/advisories/GHSA-86w9-cpqp-85rv). الفحص الخام للموبايل **ليس نظيفًا**؛ الاختبارات تتحقق من الشيفرة المصححة المثبتة ومن السلوك الفعلي، ولا تخفي نتائج npm ولا تغيّر أرقام الإصدارات لتجاوزها.

تبقى إشعارات Supabase للدوال التي تنفذ بصلاحيات المالك. دوال عرض الملف العام وإدارة الحساب والإشراف مقصودة، مع مسار بحث فارغ وفحص هوية/صلاحية وحدود البيانات. اختبارات الدور العادي والزائر أكدت منع العمليات المحمية. الجدولان الداخليان اللذان لا يملكان سياسة RLS يبقيان محجوبين عن العملاء. إشعارات سياسات الحسابات المجهولة تحتاج قراءة شروط السياسة؛ اختبار الزائر أكد منع النشر والتعليقات والتقييمات والاطلاع على المحتوى الخاص، مع السماح بتصفح المحتوى العام. لم تُحذف سياسة سليمة لمجرد إزالة إشعار.

هذا فحص للشيفرة والاعتمادات والصلاحيات والواجهة؛ ليس اختبار اختراق خارجيًا ولا ضمانًا بعدم وجود أي ثغرة. إعدادات Auth الإدارية غير المتاحة عبر اتصال هذه الجلسة، ومنها حالة حماية كلمات المرور المسربة، لا تُعد متحققة بهذا التقرير.

## التحقق والإصدار

- نجحت فحوص TypeScript وlint والبناء الإنتاجي لمشروع الويب.
- نجح 384 اختبار Vitest، و31 فحص توصيات، و37 فحص نتائج تحضير.
- نجحت اختبارات الموبايل والبيانات والتحضير وتطابق الوحدات المشتركة وفحص نصوص اللغات.
- اكتمل تصدير Expo لمنصات iOS وAndroid والويب؛ لا يمثل ذلك اختبار جهاز فعلي أو ملف TestFlight جديدًا.
- نجحت الجولة النهائية لجميع اختبارات الواجهة: 231 اختبارًا دون إخفاق، بما فيها البحث والتسجيل وإرسال الوصفات باللغات الثماني.
- بعد تنظيف التصدير النهائي نجحت ثمانية اختبارات بحث إضافية، وتأكد تطابق محتوى الوحدات المصدرية في منصات التصدير الثلاث مع النسخة التي اختُبرت.
- نجحت اختبارات SQL للغات والبحث والمساعد وصلاحيات الزائر وخصوصية الحساب، واختبارات الأمان للقراءة فقط. كل اختبارات البيانات استخدمت rollback. ثلاثة اختبارات إضافية ببيانات مؤقتة لم تُحسب ضمن النجاح بسبب خطأ اتصال requestState؛ استُخدمت فحوص صلاحيات للقراءة فقط للتحقق من الضوابط المطلوبة دون إنشاء بيانات جديدة.

المستودع المستهدف للنشر هو [elqallaf09/BeanMora](https://github.com/elqallaf09/BeanMora)، وهو عام. أذن المستخدم صراحة بإعادة الرفع إليه والدمج بعد نجاح الفحوص ونشر تحديث الويب. سير نشر الإصدار 0.5.35 مخصص للويب، ويتحقق من وجهة BeanMora وإعدادات الإنتاج والإصلاحات الأمنية المثبتة. لا تُحسب نتيجة نشر إلا بعد التحقق من تشغيل Expo ومن النسخة الحية، ولا يُعد هذا إصدارًا جديدًا إلى TestFlight.

عند فحص النشر على GitHub ظهر تحديثان تصحيحيان مطلوبان لـ Expo؛ ثبتت النسختان Expo 57.0.29 وexpo-asset 57.0.20. قُسم اختبار قاموس البحث الشامل إلى حالات مستقلة لكل مفهوم مع إبقاء جميع التأكيدات، بدل جمع القاموس كله في مهلة واحدة من خمس ثوانٍ. أصبح عدد اختبارات الوحدات للويب 842. أُعيد فحص الاعتمادات المصححة وتوافق اللغات وتصدير المنصات، وتبقى نتيجة فحوص الفرع والدمج والنشر مثبتة في طلب الدمج.

كشف فحص النسخة الحية الأولى بقاء تنبيه ثابت مولّد من مستورد الوصفات، وكلمة عدم تحديد التدفق، بالإنجليزية في اللغات الإضافية. صُححت الحالتان لكل اللغات الست، مع مراجعة صياغة تنبيه الثلج والصبات وأزرار المقارنة والشرح. يقتصر التغيير على الرسالة المعروفة وقالب الصب المعروف، وتبقى الأسماء والنصوص الحرة والمقادير الأصلية محفوظة. أُضيفت البيانات الفعلية إلى اختبار الواجهة حتى يتحقق من غياب العبارات الإنجليزية في هذه الحالات. تُسجل نتائج الفحص والنشر اللاحق في طلب التصحيح.

شملت المراجعة الحية أوصاف مكائن الإسبريسو وقيم مواصفاتها المعروفة، مثل التسخين والتشغيل اليدوي وسعة الماء. أُضيفت ترجمات مراجعة لهذه القيم مع الحفاظ على الأسماء والمقادير، واستُخدم تنسيق السعر والتاريخ المناسب للغات الإضافية. تبقى النصوص الحرة غير المعروفة بلغتها الأصلية.
